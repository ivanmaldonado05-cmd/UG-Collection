# UG Collection

Catálogo online de relojes Pagani Design (Paraguay) con panel de administración.

- **Sitio:** HTML/CSS/JS vanilla, trilingüe (ES/PT/EN), consultas por WhatsApp.
- **Panel:** `/admin/` — PHP + MySQL en el hosting; modo demo (guardado en el navegador) cuando no hay servidor.

```bash
node _build/serve.mjs 5510
```
